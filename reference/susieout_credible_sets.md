# SuSiE-OUT credible sets

Credible sets are formed separately for each single-effect component and
may contain tested or omitted variants. Probabilities are normalized
conditional on a non-null sparse effect; the returned
`nonnull_probability` preserves the unconditional component support.

## Usage

``` r
susieout_credible_sets(fit, coverage = 0.95)
```

## Arguments

- fit:

  A `susieout_fit` object.

- coverage:

  Target coverage of each credible set, in (0, 1).

## Value

A list of class `susieout_credible_sets` with one data frame per
single-effect component. Each data frame lists the variants in the set
with their `state` (`"inside"` or `"outside"`), unconditional
`probability`, `conditional_probability` given a non-null effect, and
`cumulative` conditional probability. Components with no non-null
support give empty data frames. The coverage is stored as an attribute.

locus <- susieout_simulate_locus(1, architecture = "entirely_omitted")
fit <- susieout_fit(
  locus$z, locus$n, locus$R_analysis, locus$wgs_ld, locus$examined_ids
)
sets <- susieout_credible_sets(fit)
Filter(nrow, sets)
